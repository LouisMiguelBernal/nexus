`app.py` + `api/*` routers + `services/*` without changing the HTTP surface.

Produced by an 11-agent mapping-and-verification pass (7 read-only mappers -> spec -> 3
adversarial verifiers -> completeness critic; 1.67M tokens, 46 min). The verifiers'
findings are reproduced in full because several describe failures that are import-clean,
lint-clean and only appear on a request.

## Shared-state design

PICK (a): a frozen AppState dataclass built in app.py, stashed on app.state, reached through one FastAPI dependency. Routers keep MODULE-LEVEL `router` objects and MODULE-LEVEL `async def` handlers - no closures.

```python
# backend/core/state.py   (leaf: `from __future__ import annotations` + TYPE_CHECKING imports only)
@dataclass(frozen=True, slots=True)
class AppState:
    symbols: SymbolRegistry[EngineBundle]   # replaces the 13 dicts at main.py:142-156
    store:   Store                          # backend/data/store.py
    bus:     EventBus                       # backend/core/bus.py
    supervisor: Supervisor
    caches:  Caches        # strip/deriv/news/sentiment/alpha/dvol/symbols/klines TTLCache+SingleFlight pairs
    feeds:   Feeds         # ws_manager, binance_data, okx_data, mexc_data, deribit_feed, news_feed, macro_feed
    risk:    RiskBundle    # breaker, kelly_sizer, var_calculator, pm_client, regime_classifier
    macro:   MacroBundle   # calendar, gate, sentinel_bridge, world_state
    ai:      AIBundle      # gemma4, finbert, brief_generator
    execution: ExecBundle  # blofin, telegram

# backend/api/deps.py   (leaf: fastapi + core.state)
def get_state(request: Request) -> AppState:
    return request.app.state.nexus          # set once in create_app()
StateDep = Annotated[AppState, Depends(get_state)]

# backend/api/orderflow.py   (the shape every router uses)
router = APIRouter(prefix="/api", tags=["orderflow"])

@router.get("/cvd/{symbol}")
async def get_cvd(symbol: str, state: StateDep) -> dict:
    b = state.symbols.get(symbol)                 # was _ensure_symbol_engines + cvd_computers.get
    if not b.cvd:
        raise HTTPException(status_code=500, detail="engine unavailable")
    return {"symbol": symbol.upper(), "timeframes": b.cvd.get_multi_timeframe()}
```

WHY IT BEATS (b) THE FACTORY PRECEDENT, HERE SPECIFICALLY. make_router closures make handlers unreachable by name, and this codebase already pays that price: because the matrix handler is a closure, the lifespan warm cannot call it and falls back to an unauthenticated localhost GET at main.py:896-902, which returns 401 whenever a token is configured (ops/auth.py:37,82,111-145) while main.py:903 still logs "default-view caches warmed". Five more call sites would inherit that problem - lifespan calls get_klines/get_crypto_strip/get_alpha/get_derivatives_strip directly (main.py:887-893), get_indicators awaits get_klines at main.py:3293, and get_research_brief awaits get_indicators and get_brief at main.py:3645,3649. With module-level handlers those stay function calls: `await chart.get_klines(sym, state=state, interval="1h", limit=500)`. api/matrix.py and api/world.py keep their factories untouched; app.py passes MatrixStateAdapter(state) and state.macro.world_state.

WHY IT BEATS (c) A MODULE-LEVEL REGISTRY IN core/. That is the process-global we are removing, re-spelled. It keeps import-time side effects (the 16-thread pool at main.py:2711, the token-file read at main.py:952), makes create_app() non-reentrant so two apps in one pytest process share engines, and removes no import edge - api modules would import the registry module which imports the engine constructors, the same edge as (a) but with no seam to inject a fake.

HOW IT KILLS THE MAPPED CYCLES. The dependency direction is strictly app.py -> api/* -> {core, data, services, computation, risk, macro}. `request.app.state.nexus` is a runtime attribute read, not an import, so no api module ever names backend.app - which is the absolute rule, since backend.main already imports backend.api.matrix (main.py:36) and backend.api.world (main.py:39). The four specific cycles the state map found are broken by placement, not by discipline alone: _afetch/_binance_pool/_binance_fut_get move to backend/data/binance_rest.py (imports only data.http + ops.logutil); _VALID_INTERVALS (defined main.py:2672, read main.py:1267-1268) moves to backend/config.py, a leaf main.py already imports; _ensure_symbol_engines (main.py:298-333, 20 call sites) becomes SymbolRegistry+EngineBundle in backend/services/engines.py, a leaf; the lifespan pre-warm becomes backend/services/warmup.py, which app.py imports and which imports api modules - app -> services -> api -> (nothing back).

HOW IT KEEPS HANDLERS TESTABLE WITHOUT BOOTING THE APP. `state` is an ordinary keyword argument, so `await get_cvd("BTCUSDT", state=make_state(symbols=FakeRegistry()))` runs the handler with no TestClient, no lifespan, no sockets, no sqlite. For wire-level tests, `create_app(state=fake)` mounts the real routers over a fake state - which is also how the contract test in step 1 gets an OpenAPI document without starting any background work. Frozen+slots is deliberate: nothing may rebind a field (there is no `global` statement anywhere in main.py today - the only attribute write is `_matrix_state.ws_manager = ws_manager` at main.py:1007), while the dicts and objects inside stay mutable, which is exactly the existing semantics.
